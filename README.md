# Pády Drill

Interactive Czech case drill built from *Česky krok za krokem 1* (Lekce 1–24): 7 cases, 597 items, each with a
bilingual (CZ/EN) explanation of *why* the case is used and the typical wrong forms. Three modes: by case,
mixed (pick the case first, then the form) and contrast (items where cases get confused). Single HTML file, no backend.

Live: https://umutaltinok-afk.github.io/pady-drill/

Add to the iPhone Home Screen for a full-screen app. Progress and settings stay in the browser.

Terminology follows the textbook: Ma / Mi / F / N (maskulinum animatum / inanimatum, femininum, neutrum).
